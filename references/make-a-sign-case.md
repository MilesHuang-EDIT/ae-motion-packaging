# Make a Sign 案例

真实流程：脚本与视觉参考 → 风格图 → 代表段动效 → 分段制作 → BGM节奏调整 → 奖项差异化 → 本地化 → 紧凑交付。

可复用的取舍：

- 2.5D 场景有前后景与视差；镜头快速抵达后减速停住，取消抵达后的左右晃动。
- 奖项建立层级，展示框按环境设计，功能演示保证观看面积。
- 音乐约30秒揭晓固定，通过审片比较转场，后来使用每拍一次的奖杯细节快切，不把空间穿越当唯一形式。
- 中英文分别排版，中文奖项改为单行，数据说明单独放大。
- 仅需一段时提取独立 AEP，检查依赖、便携性，避免整个项目越来越臃肿。

项目专属参数：3840×2160、30fps、125BPM；英文 Montserrat、中文 Noto Sans S Chinese；工业科技/餐厅智能硬件环境；175/121/23数据；个别版本背景40%纯黑。新项目不自动沿用。

## 可迁移的方法

- 用输出约定明确每段的分辨率、帧率、帧数和音轨要求。
- 对局部文字改版，在相同时间点比较修改区域以外的画面，检查是否出现意外变化。
- 将原生工程重开、视频解码和ZIP完整性作为不同检查步骤。
- 项目素材、原生工程及原始审计记录由具体项目管理；本仓库提供流程说明和通用辅助脚本。
